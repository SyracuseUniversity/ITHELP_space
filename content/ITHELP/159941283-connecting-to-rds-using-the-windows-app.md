## Overview

---

This page outlines the steps to connect to RDS using the Windows app on supported laptop and desktop operating systems. At present, both Windows and macOS are supported.

If you'd rather access RDS directly within your web browser, please refer to the "[Remote Desktop Services via Browser](https://su-jsm.atlassian.net/wiki/x/pYKICQ)" page for guidance.

### Install the Windows App

Before using the Windows App to connect to RDS, you must first install the software onto your device. Use the links below to download and install the Windows App for either WindowsOS or MacOS:

Download and Install for [WindowsOS](https://apps.microsoft.com/detail/9n1f85v9t8bn?rtc=1&hl=en-US&gl=US)

Download and Install for [MacOS](https://apps.apple.com/us/app/windows-app/id1295203466?mt=12)

---

### Connect to RDS via Remote Desktop

1. Launch the Windows App and click “Sign In”. Use your Syracuse credentials (SUMail address & NetID password) to login.

![A screenshot of the Windows App sign in screen](https://answers.atlassian.syr.edu/wiki/download/attachments/159941283/step1%201.JPG?api=v2)

2. You may be presented with information about the Windows App. You can read each page and click *Done* afterwards, or press *Skip* to proceed to the next step.

![A screenshot of the Windows App welcome screen](https://answers.atlassian.syr.edu/wiki/download/attachments/159941283/step2%201.JPG?api=v2)

3. From the Devices page, choose the remote environment you wish to access and select “Connect”.

![A screenshot of the Windows App Devices screen](https://answers.atlassian.syr.edu/wiki/download/attachments/159941283/step3%201.JPG?api=v2)

4. If you receive a popup asking “Allow remote desktop connection”, select *Yes* to continue.

![A screenshot of a popup asking Allow Remote Desktop Connection](https://answers.atlassian.syr.edu/wiki/download/attachments/159941283/step4%201.JPG?api=v2)
