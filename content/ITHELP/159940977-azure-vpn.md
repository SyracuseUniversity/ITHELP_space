Syracuse University provides the Azure VPN service as a multi-factor VPN solution for access to specific systems and services on campus. The Azure VPN is intended to support use scenarios that **are not covered** by other [Remote Access](https://answers.atlassian.syr.edu/wiki/spaces/ITHELP/pages/159942121/Remote+Access) methods.

Once a use scenario is in place for access to a specific system or service, please use the instructions below to install the Azure VPN client.

If you believe you need access to this solution, please work with your [academic](https://its.syr.edu/contact_its/school-and-college-support-contact-information/) or [administrative](https://its.syr.edu/contact_its/departmental-support-contact-information/) support personnel as this solution is not open and available to all users.

The ITS Help Desk does not provide users with access to this resource, please refer to the above note if you need or believe you need access for Azure VPN.

## Installation and configuration of the Azure VPN

- Depending on your Operating System, please download the matching the Azure VPN client:

  - Azure VPN client for **Windows**: <https://www.microsoft.com/en-us/p/azure-vpn-client/9np355qt2sqb?activetab=pivot:overviewtab>
  - Azure VPN client for **macOS**: <https://apps.apple.com/us/app/azure-vpn-client/id1553936137?mt=12>

## Troubleshooting connection issues in Windows

### “Socket is not connected”

1. If you encounter an error while logging in that states: “the socket is not connected,” this is normally due to third-party antivirus software, such as Avast, blocking your connection.

![azuress1.jpg](https://answers.atlassian.syr.edu/wiki/download/attachments/159940977/azuress1.jpg?api=v2)

2. You may need to allow the Azure VPN client to communicate through your antivirus software before you are able to connect.

### “Failure in acquiring Microsoft entra token”

1. If you encounter an error while logging in that states: “Failure in acquiring Microsoft entra token,” this is often fixed by using the *Clear Saved Account* feature.
2. Click the three dots (…) next to the Syracuse University profile.
3. Select **Configure**,then select **Clear Saved Account**, and then **Save.**

![azuress2.jpg](https://answers.atlassian.syr.edu/wiki/download/attachments/159940977/azuress2.jpg?api=v2)

4. After saving, attempt to connect again.

### “The operation was cancelled by the user”

#### If you encounter an error while logging in that states: “The operation was cancelled by the user,” try the following steps:

1. Close Azure VPN.
2. Open a command prompt as Admin.
3. Right click the *Start* button and choose *“Run.”*

![runimage.jpg](https://answers.atlassian.syr.edu/wiki/download/attachments/159940977/runimage.jpg?api=v2)

4. Type *cmd* into the box and then press *Ctrl+Shift+Enter* on your keyboard. Do *NOT* click the OK button.

![cmdimage.jpg](https://answers.atlassian.syr.edu/wiki/download/attachments/159940977/cmdimage.jpg?api=v2)

5. You should see a command prompt window that says Administrator in the title bar. Type the following and press enter after each line:

   *sc config wanarp start= auto*
   *sc start wanarp*

![image-20250322-162000.png](https://answers.atlassian.syr.edu/wiki/download/attachments/159940977/image-20250322-162000.png?api=v2)![image-20250322-162023.png](https://answers.atlassian.syr.edu/wiki/download/attachments/159940977/image-20250322-162023.png?api=v2)

6. Close the command prompt window. Start the VPN and try to connect again.

## macOS Install

1. Once installed, launch the client, press the “plus” symbol in the lower left corner and choose **Import** from the provided options.

   ![](https://answers.atlassian.syr.edu/wiki/download/attachments/159940977/1%20Client.png?api=v2)![](https://answers.atlassian.syr.edu/wiki/download/attachments/159940977/2%20add%20import.png?api=v2)
2. Use the XML file provided below to import the SU VPN settings:

   [Syracuse University Azure VPN Configuration File.xml](https://sumailsyr.sharepoint.com/sites/ITS-CISInfrastructure/_layouts/15/download.aspx?UniqueId=b92e5519%2D731d%2D4a9e%2D8356%2De0c54675f7d4)

   ![](https://answers.atlassian.syr.edu/wiki/download/attachments/159940977/Screen%20Shot%202021-12-16%20at%209.13.06%20AM.png?api=v2)
