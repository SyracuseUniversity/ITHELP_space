By default Windows 10 will update your computer automatically. Use the instructions below to ensure this is occurring. Windows 11 also does its updates automatically by default and we do not recommend looking to turn that function off as updates can provide quality of life as well as security updates that would otherwise be necessary.

# Step 1: Open Windows Update Settings

Using the Windows 10 search bar in the bottom left search "Windows Update Settings" and select the systems settings link that populates.

![Windows Update Settings menu](https://answers.atlassian.syr.edu/wiki/download/attachments/159940855/windowsupdatesearch.PNG?api=v2)

# Step 2: Select Automatic Updates

Once in Windows Update Settings select "Advanced Options".

![Advanced options selected](https://answers.atlassian.syr.edu/wiki/download/attachments/159940855/wusettings.PNG?api=v2)

Ensure that Automatic is selected in the drop down. You can now close the settings window.

![Automatic updates selected](https://answers.atlassian.syr.edu/wiki/download/attachments/159940855/selectautomatic.PNG?api=v2)

Your Windows 10 will now update automatically.
