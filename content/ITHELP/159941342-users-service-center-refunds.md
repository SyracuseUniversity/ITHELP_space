# Providing Refunds for Failed Print Jobs

## 1 - Identify Client Refund Request

Service Center admins will only provide refunds to failed print jobs in public locations.

- If the print job does qualify for a refund, proceed with the steps below.
- If a user is requesting a refund for a print job at a departmental location or specialty printing task, please redirect them to the [organizational unit administrator](http://its.syr.edu/contactus.html).

Specialty Printing

Some departments, such as VPA and Architecture, have more robust printing options that include varying print sizes and materials. Refunds for these refund requests should be directed to the [organizational unit administrator](http://its.syr.edu/contactus.html).

[Return to Top](https://answers.atlassian.syr.edu/wiki/spaces/ITHELP/pages/159941342/Users+-+Service+Center+Refunds#Users-ServiceCenterRefunds-topofp)

## 2 - Locate the User in the Admin Interface

To begin a refund, log into the administrative interface located at [printing.syr.edu/admin](https://printing.syr.edu/admin). Locate and click on the Users tab. 

 ![](https://answers.atlassian.syr.edu/wiki/download/attachments/159941342/userlist.PNG?api=v2)

Search for the user by inputting their SU NetID into the Quick find field and click the ">" button. 

![](https://answers.atlassian.syr.edu/wiki/download/attachments/159941342/userfilteredit.png?api=v2)

You can also filter the list of users using the filter feature. Simply click Filter off, make the desired selections. If the Filter is "on", click "clear" to begin a new filter.

![](https://answers.atlassian.syr.edu/wiki/download/attachments/159941342/userfilter.PNG?api=v2)

Click "Apply filter" to update the results tables.

![](https://answers.atlassian.syr.edu/wiki/download/attachments/159941342/applyfilteredit.png?api=v2)

Details - Audit Only

The default user details page can not be changed by administrators with this role. If you feel a field should be changed or have general questions about the details page, please contact the print management technical team by emailing [pmtt@syr.edu](mailto:pmtt@syr.edu).

[Return to Top](https://answers.atlassian.syr.edu/wiki/spaces/ITHELP/pages/159941342/Users+-+Service+Center+Refunds#Users-ServiceCenterRefunds-topofp)

## 3 - Locate the Users Job Log

Once in the user's account page, locate the user's job log. You can do this by clicking on View user's job log in Actions or by simply clicking Job Log in the sub-tabs above.

![](https://answers.atlassian.syr.edu/wiki/download/attachments/159941342/useractionsedit.png?api=v2)

![](https://answers.atlassian.syr.edu/wiki/download/attachments/159941342/userbar.PNG?api=v2)

Clicking edit in the filter section will reveal the ability to isolate particular print jobs and/or locations of print attempts.

![](https://answers.atlassian.syr.edu/wiki/download/attachments/159941342/jlfilteroptions.PNG?api=v2)

[Return to Top](https://answers.atlassian.syr.edu/wiki/spaces/ITHELP/pages/159941342/Users+-+Service+Center+Refunds#Users-ServiceCenterRefunds-topofp)

## 4 - Verify Refund Availability

Once you see the print job requiring a refund, the status column of the user's job log will indicate if a refund is available.

- Refund Available - A refund is available only if Refund is clickable in this location. If so, click on Refund to proceed.
  ![](https://answers.atlassian.syr.edu/wiki/download/attachments/159941342/refund.PNG?api=v2)
- Refund Not Available - A refund is not available if Refunded is indicated in this status column. Refunded status indicates this task has already been performed by another administrator. If this is the case, additional refunds for this print job are not allowed
  ![](https://answers.atlassian.syr.edu/wiki/download/attachments/159941342/refunded.PNG?api=v2)
  For details regarding the previous refund, hover over the word Refunded in the Status column. This will reveal details about the previously performed refund including the amount refunded, refunding administrators, and included comments.
  ![](https://answers.atlassian.syr.edu/wiki/download/attachments/159941342/refundinfo.PNG?api=v2)

[Return to Top](https://answers.atlassian.syr.edu/wiki/spaces/ITHELP/pages/159941342/Users+-+Service+Center+Refunds#Users-ServiceCenterRefunds-topofp)

## 5 - Provide the Refund

On the refund page, review the job details to be sure that you have selected the correct print job to perform the refund. Enter the amount to refund which is dictated by the cost the Job Details window above. Finally, add a comment and click OK to proceed with the refund.

Cost and Refund Must Match

Administrators in this role should never provide a refund for an amount other than the cost associated with the failed print job. If a user requires being refunded for a different amount other than indicated by the cost of the refunded job or has other purse related issues, please contact the print management technical team by emailing [pmtt@syr.edu](mailto:pmtt@syr.edu) or creating a ticket in the [PMTT Orange Tracker queue](https://ot.syr.edu/browse/PMTT/).

![](https://answers.atlassian.syr.edu/wiki/download/attachments/159941342/refundjobinfo.PNG?api=v2)

Comments Required

A detailed comment is required for all refunds without exception.

The refund amount should now be added to the purse where the funds were subtracted as dictated by the user at the time of printing.

# Additional Refunds and Quota Support

If performing this refund produced and error or did not resolve the user's account issue, please contact the print management technical team by emailing [pmtt@syr.edu](mailto:pmtt@syr.edu).
