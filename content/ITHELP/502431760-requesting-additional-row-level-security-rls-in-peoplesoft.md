In some cases, you may need access to additional department, program, or payroll data within PeopleSoft after your initial access has been granted.
These requests are handled differently than your initial OrangeAccess (OA) request.

---

## When to Use This Process

Use this process **only if you already have PeopleSoft access** and need to view or manage data for additional:

- Departments or department IDs
- Programs or projects
- Payroll or financial reporting areas

If you are requesting **PeopleSoft access for the first time**, submit your initial request through [**OrangeAccess (OA)**](https://orangeaccess.syr.edu).

- When selecting the access item, select **“See more”** in the description to expand and read the full instructions before submitting.
- In the **comments field**, include the specific **departments, programs, or areas** you need access to.

📸 *Screenshot:* ![Request Center page showing Access item description with See more expanded](https://answers.atlassian.syr.edu/wiki/download/attachments/502431760/rls.png?api=v2)

### 1. Financials (FSCM)

If you need additional **department, program, or payroll access** in PeopleSoft Financials, these requests are handled through the [**Finance Jira Portal**](https://support.atlassian.syr.edu/servicedesk/customer/portal/923).

1. Navigate to the [**Finance Jira Portal**](https://support.atlassian.syr.edu/servicedesk/customer/portal/923).
2. Review the list of available **Financials Row Level Security (RLS)** request types.

   - There are several forms to choose from — each has a short description explaining when to use it.
   - Be sure to select the form that best matches your access need (e.g., ePro, General Ledger, Sponsored Accounting Management, Travel and Expense, etc.).
3. Complete the form and attach all required documentation.

   - Each form requires different information, as described in its instructions.
   - **All Financial RLS requests must include an email from your Budget Manager approving the change.**
   - Save the Budget Manager’s email as a file and attach it to the form before submitting.
4. Submit the form through the Jira portal.

📸 *Screenshot:* ![Finance Jira portal showing multiple forms to select](https://answers.atlassian.syr.edu/wiki/download/attachments/502431760/Jira%20fin%20portal.png?api=v2)

---

### 2. Human Resources and Payroll

If you need additional **department** in PeopleSoft HCM or TimeClock+, these requests are handled through the [Human Resources and Payroll (HCM) Jira/OT Portal](https://support.atlassian.syr.edu/servicedesk/customer/portal/957).

1. Navigate to the [**HCM Jira/Orange Tracker(OT) Portal**](https://support.atlassian.syr.edu/servicedesk/customer/portal/957).
2. Review the list of available **Financials Row Level Security (RLS)** request types.

   - There are multiple forms to choose from — each has a short description explaining when to use it.
   - Be sure to select the form that best matches your access need (e.g., Human Resources, Payroll, or Timeclock+).
3. Complete the form and attach all required instructions.

   - Each form requires different information, as described in its instructions.
   - **All Human Resources , Payroll, and TimeClock+ RLS requests must include an email from your Budget Manager approving the change.**
   - Save the Budget Manager’s email as a file and attach it to the form before submitting.
4. Submit the form through the Jira portal.

📸 *Screenshot:* ![Human resource and payroll jira portal showing the forms to select](https://answers.atlassian.syr.edu/wiki/download/attachments/502431760/hrpy%20jira.png?api=v2)

---

## What Happens Next

- Once your RLS request is reviewed and approved by the appropriate security team, your access will be updated in PeopleSoft.
- You will receive confirmation when the change is complete.
- Processing time may vary depending on the department.

---

✅ **Tips**

- Carefully read each form’s description in the Jira portal before selecting — it will tell you exactly what information is required.
- Attach your Budget Manager’s approval email before submitting; requests missing this step will be delayed or returned.
- You will receive confirmation in Jira when your request is submitted and again when processing is complete.
- Access changes may take up to one business day after approval to appear in PeopleSoft.
