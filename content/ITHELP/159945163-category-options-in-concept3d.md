## Title

The title is the title of the category. This is what will display in the list of categories.

## Marker Icon

A marker icon is the icon directly on the map which displays for the locations in the category. This can be a pin, pointer, arrow, or anything designating a location.

## List Icon

This is the image that displays next to the name of the category in the category list.

## Category

From here you can select where the category exists. This can be the main list or one of the existing categories and make it a sub-category

## List Position

Where in the list the category will sit relative to the other categories at the same level, depending on the level entered (Lower number, higher in the list)

## List Type

Make the category/location list inside of category expandable (All), or not at all (None). None can still hold locations, but won't show them in the list.

## Checkbox

Allows category to be selectable in the sidebar to display locations for the entire category.

## Zoom Visibility

Allows for setting a zoom level on which the locations within the category will display.

## Single Select

Only allows one sub-category within this main category to be selected at a time.

## Panorama Category

Displays panoramas within the category in full screen.

## Hidden From Sidebar

Enabling this option will make the category not visible in the sidebar, locations are still searchable within the category.

## Default Display

Automatically select category when navigated back to the home page.

## Private

This makes the category only viewable on the front end with the "Get This View" or "Share" link

MUST BE SET TO "TRUE" WHILE CATEGORY IS IN DEVELOPMENT!

## Category View

Sets map view and zoom when the category is toggled on.

## Schedule

Schedule when category is displayed on the front end.

## Marker Zoom

Set the zoom level for all locations when they are selected under this category.

## Visible

Sets all locations to be visible on the front end; if disabled, this location and all locations within are only visible in the CMS.

MUST BE SET INITIALLY TO "NO" WHILE CATEGORY IS IN DEVELOPMENT!

## Searchable

Allows locations in this category to show in search.

## Fallback Data

All sub-categories in this category without a custom description will inherit this data.

## Labels

Comma separated tags to identify similar categories that enable identification for bulk editing.

## Category pop-up

Popup description appearing at the bottom of the screen when category is selected.
