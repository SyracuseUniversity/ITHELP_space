## In order to download and retain your Syracuse University email for use in an email application please follow the steps below to create an mbox file that preserves the necessary file structure for email applications to be able to import and interact with your mailbox.

1. Add your Syracuse University email to your mail app in the Settings application under "Internet Accounts"

   ![](https://answers.atlassian.syr.edu/wiki/download/attachments/159941508/Settings%20accounts.png?api=v2)
2. Select "Exchange" as the account type.

   ![](https://answers.atlassian.syr.edu/wiki/download/attachments/159941508/Account%20type.png?api=v2)
3. Put in your SU email address and you can give the account any name you would like (this name will appear in the sidebar of the mail app to differentiate mail accounts)

   ![](https://answers.atlassian.syr.edu/wiki/download/attachments/159941508/exchange%20login.png?api=v2)
4. Use the "Sign In" option. This should bring you to a Microsoft login where you would use your SU credentials to sign in. 

   ![](https://answers.atlassian.syr.edu/wiki/download/attachments/159941508/sign%20in.png?api=v2)
5. When you launch Mail it should now show your SU email inbox in the sidebar. If you right click the inbox it will bring up a contextual menu with the option to "Export Mailbox".

   ![](https://answers.atlassian.syr.edu/wiki/download/attachments/159941508/export%20mailbox.png?api=v2)
6. Once you choose the export option it will ask you where you want to store the mbox file it will create. You can store this file anywhere you prefer but it should default to your Documents folder.  

   ![](https://answers.atlassian.syr.edu/wiki/download/attachments/159941508/mbox%20location.png?api=v2)
7. After you choose a location it should default to mbox for the format of the file being exported. Choose continue to begin the export process.

   ![](https://answers.atlassian.syr.edu/wiki/download/attachments/159941508/mbox%20format.png?api=v2)
8. Once the export is complete you can import this mailbox into the Mail app by going to the "File" option in the menubar and choosing "Import Mailboxes…"

   ![](https://answers.atlassian.syr.edu/wiki/download/attachments/159941508/import%20mailbox.png?api=v2)
9. It will present you with a File picker and you will need to navigate to where you saved your mbox file and choose it.
   *Make sure to select the outer most folder not the enclosed mbox file.*

   ![](https://answers.atlassian.syr.edu/wiki/download/attachments/159941508/mbox%20selection.png?api=v2)
10. You will see a screen like this upon completion of the import directing you as to where to locate the mailbox in the sidebar.

    ![](https://answers.atlassian.syr.edu/wiki/download/attachments/159941508/import%20completion.png?api=v2)
11. Your mail should now be found in the newly imported mailbox in the sidebar.

    ![](https://answers.atlassian.syr.edu/wiki/download/attachments/159941508/mbox%20in%20sidebar.png?api=v2)
