This document shows how to log into any Atlassian cloud application when using your 'netid@syr.edu' account. On 06/08/2023, a new security policy will be set to allow only Single Sign-On (SSO) to enter the system. Anyone using their 'netid@syr.edu' account as their email address for Atlassian, will have to use SSO to login.

### Login Process

Use your 'netid@syr.edu' **email address** at the top of the login screen. **Do not try to login with Google, Microsoft, Apple, or Slack.**

![](https://answers.atlassian.syr.edu/wiki/download/attachments/159943058/AtlassianLogin2.png?api=v2)

Next you'll see a Microsoft Azure SSO screen. Please use your email address and then password to login.

![](https://answers.atlassian.syr.edu/wiki/download/attachments/159943058/MS_Azure.png?api=v2)

After a successful login, the Atlassian application will display and function as normal.
