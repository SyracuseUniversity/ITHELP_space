Syracuse University websites, such as Myslice, may require the enabling of pop-ups in order to view desired content. Below you will find instructions on enabling pop-ups within the most commonly used browsers

# Google Chrome

When you select a link that requires a pop-up and they are currently blocked, at the end of your address bar you will see an icon that shows a browser window with a red X in the corner. Click on this, then choose “Always allow for MySlice (or other website)” and then done. Refresh the page, and then the website’s popups should work.

![A screenshot showing the steps to enable popups in Google Chrome](https://answers.atlassian.syr.edu/wiki/download/attachments/159940833/2019-04-17_12h32_07-2.png?api=v2)

# Mozilla Firefox

Whenever a up window tries to launch itself Mozilla prevents it from opening and displays a message a banner which reads "Firefox prevented this site from opening a pop-up window"

![A screenshot showing the Firefox pop-up blocked message with the Options button having an arrow pointing to it and allow pop-ups option is circled](https://answers.atlassian.syr.edu/wiki/download/attachments/159940833/Screenshot%202026-08-14%20085120.png?api=v2)

In order to view the pop-up, select "Options" on the banner. Now select "Always allow pop-ups and third-party redirects” for the site, and refresh the page to try loading the pop-up again.

# Safari

1) While in the Safari application, open the Safari Menu in the top left hand corner and select "Settings".

**Safari Menu Not Visible**

If "Safari" is not an option to the right of your Apple symbol in the top left hand corner, be sure that you click on the Safari window. If you have recently clicked on another application or your desktop, "Finder" or another application title may be here instead.

![A screenshot of the Safari menu selected with Settings being circled](https://answers.atlassian.syr.edu/wiki/download/attachments/159940833/Screenshot%202026-08-14%20at%209.00.28%E2%80%AFAM.png?api=v2)

2) Under the websites tab, look for the "Pop-up Windows" setting on the left side under the "General" box. Click on this, and then you will see a list of currently open websites. Set the specified page currently open to "Allow" using the drop-down menu on the far right side.

![The Website section of Safari Settings with Pop-up Windows selected and Block and Notify circled](https://answers.atlassian.syr.edu/wiki/download/attachments/159940833/548a9c0e-dbda-4de2-b94e-cd8a65d7eb18.png?api=v2)

3) The setting on the right side of website should now say "Allow".

![The Website section of Safari Settings with Pop-up Windows selected with Pop-ups set to allow](https://answers.atlassian.syr.edu/wiki/download/attachments/159940833/1df2d7ac-2e1c-433c-bb3d-856fd5e4b29f.png?api=v2)

Safari should now allow pop-ups to function normally on the allowed website(s).

# Microsoft Edge

## **Enabling Pop-Ups in the moment**

The default settings of Microsoft Edge will automatically block pop-ups. An icon showing a browser window with a slash through it will appear at the end of the address bar if a popup is blocked. To enable it, simply click on the box with the slash through it and then choose “Always allow pop-ups” and then press “Done”.
