## Overview

---

This page offers guidance on how to connect to RDS using a web browser.

If you prefer to access RDS through the remote desktop application, please refer to the instructions on the "[Remote Desktop Services via Windows App](https://su-jsm.atlassian.net/wiki/x/o4KICQ)" page.

### Connecting to RDS

---

1. Using a web browser, navigate to [rds.syr.edu](https://rds.syr.edu).
2. You will encounter a Microsoft login screen. Sign in using your SUMail address and NetID password:

![Microsoft login screen encountered when navigating to rds.syr.edu](https://answers.atlassian.syr.edu/wiki/download/attachments/159941285/rdspage1.PNG?api=v2)

3. You may be presented with information about the Windows App. You can read each page and click *Done* afterwards, or press *Skip* to proceed to the next step.

![The 'Welcome to the Windows App' page that appears when opening the Windows App for the first time.](https://answers.atlassian.syr.edu/wiki/download/attachments/159941285/rdspage2.PNG?api=v2)

4. From the Devices page, choose the remote environment you wish to access and select “Connect”.

![The devices page of the Windows App. ](https://answers.atlassian.syr.edu/wiki/download/attachments/159941285/rdspage3.PNG?api=v2)

5. If this is your first time logging into the remote desktop, or if you're logging in after clearing your cache and cookies, you may be presented with a popup dialog box. This box will ask for permission to allow the remote computer to access certain functions on your device. If you'd like to prevent this popup from appearing in the future, simply check the box labeled "Don’t show again" and press *Connect.*

![A popup dialogue box titled 'In Session Settings' may appear if you are logging in for the first time. The pop-up asks for permission to allow the remote computer to access functions of your device, such as printer, file transfer, clipboard, and keyboard shortcuts. Select the 'Don't show again' box before connecting to the remote desktop to prevent this pop-up from appearing in the future. ](https://answers.atlassian.syr.edu/wiki/download/attachments/159941285/rdspage4.PNG?api=v2)

After pressing *Connect,* you should be signed into the remote desktop environment. Please note that your session may start in full screen in order to enable keyboard shortcuts. If you want to exit full screen, press *ESC* on your keyboard.

### Getting Help

---

We're here to ensure you have a smooth experience with RDS. If you need assistance:

- **Students**: Feel free to reach out to the [ITS Help Desk](https://its.syr.edu/its_service_center/) directly. Call us at 315-443-2677, email at [help@syr.edu](mailto:help@syr.edu).
- **Faculty and Staff**: For the most efficient support, it's recommended to start with your respective [academic](https://its.syr.edu/contact_its/school-and-college-support-contact-information/) or [administrative](https://its.syr.edu/contact_its/departmental-support-contact-information/) support teams. They're equipped with tools and knowledge tailored to your needs.
