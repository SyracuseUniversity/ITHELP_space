# Server Creation and Management

Each department will need to install PaperCut on a designated print server. The department admin will need to determine whether adapting an existing printer server or creating a new one is the best course of action. Once the steps below have been completed, visit the [PaperCut administrative interface](https://printing.syr.edu/admin) to view the printer activity.

University Device Guidelines

Before installing any printer on campus, be aware of [Syracuse University's imaging device guidelines](https://answers.syr.edu/display/infosec011/SU+Information+Technology+Security+Standards+and+Procedures?preview=/54362577/54887652/ImagingDeviceGuidelines-G0101.pdf).
