# Overview

---

Syracuse University provides GitHub, a powerful collaboration platform for software development and beyond, to its active students, faculty, and staff. While GitHub is renowned for hosting code, it's also invaluable for managing any text-based projects like configuration files, project documentation, and more, thanks to its robust version control and collaborative features.

## Accessing the Syracuse University GitHub Organization

Use the following link to request access to the GitHub Organization.

<https://myaccess.microsoft.com/@sumailsyr.onmicrosoft.com#/access-packages/8651c0eb-0875-49cb-9c25-968cd6968bab>

---

## Once Access has been Granted:

- An email will be sent to your Syracuse University mailbox (typically within 60 minutes).
- [Create a GitHub.com account](https://answers.atlassian.syr.edu/wiki/spaces/ITHELP/pages/159942596/Creating+a+GitHub+account) or follow the instructions in the email to link any existing personal GitHub account with your Syracuse University identity by completing the sign-in process.
- After successful sign-in, you will be presented your account's "Dashboard".
- You may access the Syracuse University organization by using the "View organization" button or by navigating to the following page: [GitHub.syr.edu](http://GitHub.syr.edu)
- Request to [join an existing GitHub Team](https://answers.atlassian.syr.edu/wiki/spaces/ITHELP/pages/159942578/GitHub+Team)  or follow one of the [use case guides](https://answers.atlassian.syr.edu/wiki/spaces/ITHELP/pages/159942758/GitHub+Use+Case+Guides) to create your own.
- Be sure to customize your [GitHub Notifications](https://answers.atlassian.syr.edu/wiki/spaces/ITHELP/pages/159942598/GitHub+Notifications)

At any time, you may access the [Syracuse University GitHub Organization](http://github.syr.edu) by going to: [GitHub.syr.edu](http://GitHub.syr.edu)

## GitHub Data LifeCycle

When a user is no longer active Syracuse University community member, they will lose access to the Syracuse University GitHub organization.

Repositories existing in the Syracuse University GitHub organization must have an active SU community member associated with the repository, if not it will be deleted after 1 year.
