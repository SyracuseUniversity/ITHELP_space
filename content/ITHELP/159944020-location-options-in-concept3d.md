When creating or modifying locations in Concept3D, you have the ability to manipulate the options associated with a location. If you have nay questions on what an option does, you may hover over the [?] icon next to the option name to view more information. The following options are modifiable:

- [Title](#LocationOptionsinConcept3D-Title)
- [Icon](#LocationOptionsinConcept3D-Icon)
- [Floor Level](#LocationOptionsinConcept3D-FloorLevel)
- [Zoom Levels Visibility](#LocationOptionsinConcept3D-ZoomLevelsVisibility)
- [Category](#LocationOptionsinConcept3D-Category)
- [Media](#LocationOptionsinConcept3D-Media)
- [Description](#LocationOptionsinConcept3D-Description)
- [Keywords](#LocationOptionsinConcept3D-Keywords)
- [Labels](#LocationOptionsinConcept3D-Labels)
- [Reference](#LocationOptionsinConcept3D-Reference)
- [List Position](#LocationOptionsinConcept3D-ListPosition)
- [Visible](#LocationOptionsinConcept3D-Visible)
- [Private](#LocationOptionsinConcept3D-Private)
- [Schedule](#LocationOptionsinConcept3D-Schedule)

Some option entries and choices will be dictated by established standards and naming conventions, and are subject to approval processes prior to publishing in production.

## Title

Name as displayed in the sidebar and icon balloons.

## Icon

Icon marker displayed on map for this location.

## Floor Level

Interior floor level of location. Multiple levels possible.

## Zoom Levels Visibility

Limit locations to display at a specific zoom level. Overrides category zoom, max setting is 21.

## Category

Category to contain this location. May be placed in multiple categories.

## Media

Images and videos to be displayed.

## Description

Description and related information of location.

## Keywords

Comma separated list of words used for searches.

## Labels

Comma separated tags to identify similar categories that enable identification for bulk editing.

## Reference

Unique identifier to associate to URLs,  dynamic categories, data feeds.

## List Position

Order in which the location appears on the category list.

## Visible

Enable locations to be displayed on public map. Choose "Hidden" if locations are to appear only in CMS.

MUST BE SET INITIALLY TO "HIDDEN" WHILE LOCATION IS IN DEVELOPMENT!

## Private

Hide on public map, available only if using a specific URL.

MUST BE SET INITIALLY TO "HIDDEN" WHILE LOCATION IS IN DEVELOPMENT!

## Schedule

Time/date range to enable/disable display of location.
