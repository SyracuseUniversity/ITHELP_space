In some cases, you may need to request access for someone who is **not yourself** and **not your direct report** — for example, a colleague you support, a temporary employee, or a contractor. OrangeAccess provides a **Request for Others** option to make this possible.

---

## 1. Log in to OrangeAccess

- Open a browser and go to [orangeaccess.syr.edu](https://orangeaccess.syr.edu/).
- Log in with your NetID and password.
- After login, you’ll be brought to the **OrangeAccess Home Page** with tiles. 📸 *Screenshot:* ![OrangeAccess home page, with the Request Center tab circled](https://answers.atlassian.syr.edu/wiki/download/attachments/563380231/280a9dcc-7338-4f55-b53c-a55a1a57b40b?api=v2)

---

## 2. Submit a Request for Another Person

1. From the home page, select **Request Center**.
2. Select **Request for Others**. 📸 *Screenshot:* ![request center page with the request for others circled](https://answers.atlassian.syr.edu/wiki/download/attachments/469794957/OA-request4other1.png?api=v2)
3. Search for and select the employee you want to request access for.

   - Enter their **name** or **NetID** in the search box.
   - You may select **more than one identity** before continuing.
   - Confirm you selected the correct person.
4. Browse or search for the access items you want to request.

   - Example: Search for `HCM` and select the needed role.
5. (Optional) Add a comment explaining why you are making the request.
6. (Optional) Set an expiration date if the access is temporary.
7. (Optional) Add additional access items for the same employee.
8. At the top right, select **Review Requests**. 📸 *Screenshot:* ![access request page showing and access request selected and the review link circled](https://answers.atlassian.syr.edu/wiki/download/attachments/469794957/OA4.png?api=v2)
9. Review your selections and make any edits.
10. Select **Submit Request**. 📸 *Screenshot:* ![Review Requests page showing the selection and the submit button circled before submission](https://answers.atlassian.syr.edu/wiki/download/attachments/469794957/OA5.png?api=v2)

---

## 3. Review Your Submitted Request

1. Return to the **Home Page**.
2. Select the **Pending Requests** tile. 📸Screenshot: ![Pending request page](https://answers.atlassian.syr.edu/wiki/download/attachments/563478537/fb46aadc-aa96-404c-a2d4-1a03f6787620?api=v2)
3. Find your request and select **Details**.

   - Here you can track the current status. 📸Screenshot: ![Request center page with showing the pending request and the detail link circled](https://answers.atlassian.syr.edu/wiki/download/attachments/563478537/920dc9af-46d6-4c9c-8a21-7c5faae069e7?api=v2)
4. You’ll also receive an email confirming your request. 📸Screenshot: ![email confirmation showing the request was submitted](https://answers.atlassian.syr.edu/wiki/download/attachments/563478537/5087c440-a415-4b94-bbb4-c10749eb1920?api=v2)

---

## 4. Monitor Progress

- The request will follow the standard approval workflow:

  - **Manager approval** (if you are not the employee’s manager).
  - **Application/Data Owner approval** (governance group).
- You can monitor the request status by selecting the **Pending Requests** tile. 📸 *Screenshot:* ![Pending Requests page showing the process card](https://answers.atlassian.syr.edu/wiki/download/attachments/562921490/a9d6615c-fdcb-4c2e-9e7e-d8ef1eafe415?api=v2)
- The employee will also receive an email when their access is approved or denied. 📸 *Screenshot:* ![email sent to employee showing the access decision ](https://answers.atlassian.syr.edu/wiki/download/attachments/562921490/de7077e6-13fd-4d8f-92e8-af33b679f7b0?api=v2)

---

*✅ Tips:*

- You can always review your full request history under the **Pending Requests** tile, even after requests are complete.
- Managers can request access for **more than one person** at a time by selecting multiple identities.
- Use the **Review Requests** page to double-check that all selected team members and access items are correct before submitting.
- **Bulk uploads or department-wide requests** are not supported — requests must be made for specific individuals.
