## General Browser Support for MySlice

MySlice core applications - Human Resources (HR), Campus Solutions (CS), and Financials (FIN), as well as MySlice itself are based on Oracle's PeopleTools platform, which has specific web browser requirements.

***Note: Other applications accessed through MySlice like Blackboard, Bills on the Web, Housing, Parking, etc. may have different browser support requirements which are not listed here.***

Oracle officially supports "the current major (Stable) release, and the most prior major release" of Chrome, Firefox, Safari, and MS Edge
As of August 2020, Internet Explorer (IE) is **not** supported by Oracle and therefore is not supported for use with MySlice.

Oracle's official and most up-to-date support list can be found here: <http://www.oracle.com/technetwork/indexes/products/browser-policy-2859268.html>

**In general, unless directed otherwise due to a known compatibility issue, it is best to use the latest current stable release of Chrome, Safari, Firefox or Edge.**

**On mobile devices - Safari for iOS, and Chrome\*\* for Android.**

\*\* **Chrome is the only officially supported browser on Android devices,** many android devices come with an alternate "android web browser" that can be branded by the vendor, often the icon is simply "internet". These browsers, and any browser other than chrome, are *specifically not supported.* Download Google Chrome from the Google Play Store and replace the default browser.

As a general rule of thumb, if you encounter issues with the services displaying or providing you with an error, clearing your cookies and cache or restarting your device in most cases will resolve your issues. **You can find instructions on how to manage your browser here**: [Managing Browsers](https://answers.atlassian.syr.edu/wiki/spaces/ITHELP/pages/159941373/Managing+Browsers). If it does not it will provide your support representatives with a good starting point for troubleshooting!

If you have any difficulty completing functions or services within these systems using the latest browser from the supported list, please contact our Service Center at 315.443.2677 or [help@syr.edu](mailto:help@syr.edu).

## MySlice Applications with Known Special Requirements or Issues

***(As of August 2023)***

- **Bills on the Web** allows access to Student Bills after students/parents are logged in via MySlice.  The application utilizes OnBase Docpop from the Bursar pages to display the student bills. As with PeopleSoft, newer browsers may work properly, however the browsers certified by OnBase for version 16 are:

  |  |  |  |  |
  | --- | --- | --- | --- |
  | **OnBase Compatible Browsers** | **Platform** | **Evergreen** | **Notes – Updated as of August 2022 for OnBase Foundations version EP5** |
  | Apple Safari 14.0.x+ | macOS | Yes | Supported by BU |
  | Firefox 78 ESR and newer | macOS Windows | No | Recommended for Windows. Recommended for macOS because version upgrades can be controlled.  Supported by SU |
  | Firefox 87+ (non ESR) | macOS Windows | Yes | There is a bug in the chrome engine underlying Firefox which does not allow Portfolio type PDFs to be opened. We recommend not storing Portfolio PDF documents in OnBase. |
  | Google Chrome 89+ | macOS    Windows | Yes | There is a bug in the chrome engine which does not allow Portfolio type PDFs to be opened. We recommend not storing Portfolio PDF documents in OnBase. |
  | Microsoft Edge on Chromium 89+ | Windows | Yes | **OnBase Workflow may not be available in this browser.** Supported by SU |
  | Microsoft Internet Explorer 11 | Windows | No | **NOT SUPPORTED BY SU**    Performance may be an issue when applying complex filters to workflow queues with many documents. Use Firefox or Chrome if you encounter this issue. |
- **My Reports** is accessed from the Administrative Applications pagelet on MySlice.

  - **Requires Internet Explorer 11 in** [**compatibility mode**](https://support.microsoft.com/en-us/help/17472/windows-internet-explorer-11-fix-site-display-problems-compatibility-v)**.** *No other browsers are supported by My Reports, and there are no current plans for additional browser support.* Financials/MyReports users only need to use IE 11 when planning to access My Reports. Other access does not require IE and will generally work better in other more modern browsers.
  - The "Zoom" (screen display) in your IE 11 browser also needs to be set at 100%
