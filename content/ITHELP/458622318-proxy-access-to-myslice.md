MySlice proxy accounts are created by SU students and applicants to share limited access to their information within MySlice with someone (ex: the ability to pay bills). The student or applicant controls the level of access granted.

Starting October 3, 2025, proxies can log into MySlice using their personal email accounts instead of remembering and using separate MySlice credentials to log into MySlice.

Proxy accounts that were created before October 3, 2025 will not work after October 2, 2025. A new account will need be setup by the student or applicant for each proxy.

## Creating the Proxy Account

Students/applicants need to create a new proxy account on or after October 3, 2025:

1. Students/applicants log into MySlice and click on Share My Access to create a new account for their proxy using the person's email address. They select what access the proxy account will have to their information as part of this process.
2. Proxies receive a Microsoft invitation email to complete account setup if they are not already using that email address to access resources at SU.
3. Once setup is complete, the email address is linked to a Microsoft account for SU, and the email address can now be used to log into MySlice.
4. **Please allow 24 hours for activation to make a payment on the students account.**

## How Proxies Log In

Once setup is complete, proxies can access [MySlice.syr.edu](http://myslice.syr.edu) using their email account.

- Non-Microsoft accounts (Gmail, Yahoo, Verizon, etc.): Receive a verification code at the proxy email address
- Microsoft accounts (Outlook, Hotmail, MSN, work/school): Use the email account’s regular login credentials

## Enhanced Security with Multi-Factor Authentication

To better protect student/applicant and proxy data, MySlice will require multi-factor authentication (MFA) for all proxy logins. During login, you'll need to provide an additional verification method such as:

- A code from an authenticator app
- A text message verification code

This security measure has been standard for students, faculty, and staff, and will now be extended to proxies for consistent protection across all MySlice users.
