Sync'd Once Daily

Note that the user lists within PaperCut sync once daily. Make note of when a client's account has been activated. If it was the same day, they may not be visible until the next morning.

Audit Only

No administrative roles can make changes to user accounts beyond the items listed below. If you require help with a user in the SU print management system, contact the Print Management Technical Team by emailing [pmtt@syr.edu.](mailto:pmtt@syr.edu.)

# Finding and Filtering User Lists

In order to locate users, navigate to the Users tab.

![](https://answers.atlassian.syr.edu/wiki/download/attachments/159941175/userlist.PNG?api=v2)

## Filtering User Lists

In order to search for a user, simply input the student's SU NetID in the search field. Note that administrators in the Admin role will only be able to see users in their user groups.

![](https://answers.atlassian.syr.edu/wiki/download/attachments/159941175/usernetid.PNG?api=v2)

To filter the results of the user list, click Filter on or Filter off (whichever is available).

![](https://answers.atlassian.syr.edu/wiki/download/attachments/159941175/userfilters.PNG?api=v2)

More advanced filtering options should now be visible. If the filter was on, click "Clear" to set a new filter.

Limited User List

Note that groups listed will only include those managed by the administrator currently logged in.

![](https://answers.atlassian.syr.edu/wiki/download/attachments/159941175/userfilterdetails.PNG?api=v2)

Be sure to click Apply Filter for the results table to update.
