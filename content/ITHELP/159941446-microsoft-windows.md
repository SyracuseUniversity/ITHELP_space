## Windows 10 S Mode

Windows 10 S is a version of Windows designed to be more secure and robust. The limitations placed on Windows 10 S to achieve this security include using Edge as the exclusive browser, Bing as the exclusive search engine, and restricting applications to only those purchased through Microsoft's App Store. These limitations prevents many useful or needed programs from being installed.  **Windows 10 S Mode devices are not recommended and support by ITS is limited to 'best effort'.**Learn more about Windows 10 S mode on the [Microsoft Windows 10 S mode FAQ](https://support.microsoft.com/en-us/help/4020089/windows-10-in-s-mode-faq).

**Please read!**

It is not recommended to remove Windows 10 S Mode off the device in question. As with many things, removing the framework of what the device was intended to support can cause all sorts of instability and issues. If a user needs something that would require that, it would be better for them to either purchase a different device, or use one of the remote labs that may have the applicable software/application they need.
