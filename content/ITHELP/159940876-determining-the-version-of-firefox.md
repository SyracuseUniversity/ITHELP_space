How to determine the version of Firefox that you are running

![](https://answers.atlassian.syr.edu/wiki/plugins/servlet/confluence/placeholder/unknown-macro?name=its-toc&locale=en_US&version=2)

# Mac

1. Select the Firefox menu, then "About Firefox."

   ![firefox menu with about firefox selected underneath](https://answers.atlassian.syr.edu/wiki/download/attachments/159940876/Screen%20shot%202012-02-16%20at%2010.25.48%20AM.png?api=v2)
2. In the display window, the version will appear below the word Firefox

   ![](https://answers.atlassian.syr.edu/wiki/download/attachments/159940876/Screen%20Shot%202018-08-06%20at%204.30.38%20PM.png?api=v2)

# Windows

## Newer versions of Firefox

1. Click the Menu button in the top right corner
2. Select the Help option at the bottom of the menu
   ![Firefox menu screen](https://answers.atlassian.syr.edu/wiki/download/attachments/159940876/FIrefox%20Version1.png?api=v2)
3. Select "About Firefox"
   ![Firefox pull down menu](https://answers.atlassian.syr.edu/wiki/download/attachments/159940876/Firefox%20version2.PNG?api=v2)
4. A dialogue box will appear and the version number will be located underneath the word Firefox
   ![Firefox system info screen](https://answers.atlassian.syr.edu/wiki/download/attachments/159940876/Firefox%20Cache3.JPG?api=v2)
