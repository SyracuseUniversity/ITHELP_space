If you have questions or issues with OrangeAccess, use the contacts below to ensure your request goes to the right team.

---

## System Issues

If you encounter a problem in OrangeAccess (login issues, request not processing, errors, etc.):
→ Submit a ticket to the [OAHELP](https://support.atlassian.syr.edu/servicedesk/customer/portal/924/group/1213/create/2622) queue.

---

## Access Design & ERP Security

For issues related to:

- New entitlements, access profiles, or roles
- ERP application access questions
- Department changes or left SU reports

→ Submit a ticket to the [OAHELP](https://support.atlassian.syr.edu/servicedesk/customer/portal/924/group/1213/create/2622) queue.

---

## Add Requestable Entitlements

If you need to Add or Change an entitlement in OrangeAccess:
→ Submit a request through [OAHELP JIRA form](https://support.atlassian.syr.edu/servicedesk/customer/portal/924/group/1213/create/2552).

---

## New Applications

If you need a new application added to OrangeAccess:

- Use the [[How to Request a New Application to Be Added](https://answers.atlassian.syr.edu/wiki/spaces/ITHELP/pages/470647762/How+to+Request+a+New+Application+to+Be+Added)] guide.

---

## Need Help Deciding?

If you’re unsure where your issue belongs, submit to the [OAHELP](https://support.atlassian.syr.edu/servicedesk/customer/portal/924/group/1213/create/2622) queue. The IAM team will review and reassign if needed.
