[Eduroam](https://www.eduroam.org/) (**edu**cation **roam**ing) is a secure, worldwide wireless network access service developed for the international research and education community. Eduroam provides students, faculty, and staff from participating institutions simple, instant and secure access to the Internet when visiting each other’s institutions.

With hundreds of thousands of wireless access-points sharing a common network name or SSID, eduroam acts as one large, world-wide, wireless hotspot. Eduroam is offered at more than 5,500 institutions, in more than 50 countries, with more than 160 institutions in the United States. For lists and maps showing all institutions participating in eduroam visit the eduroam website at <https://eduroam.org/>. This information is updated frequently as more institutions join Eduroam.

Eduroam is managed by the Global eduroam Governance Committee, which is made up of several regional administrative entities. Syracuse University is a member of eduroam-US.

# Connecting to eduroam

Users can quickly and easily configure their device to connect to eduroam by using the SU eduroam onboarding portal. Doing so will require an initial Internet connection (e.g. using mobile data). Then follow these steps:

- Use your web browser to go to [eduroamsu.syr.edu](https://eduroamsu.syr.edu).
- It will prompt you for your NetID login information if you aren’t already signed in. If you need to manage your NetID credentials you can do so by visiting [netid.syr.edu](https://netid.syr.edu/selfserv/)
- The web page will automatically select the correct profile for your device/operating system - e.g.: ‘Windows’ / ‘iOS’ / ‘Android', click on the link to download the installer.
- Follow the guides below to download and install the app which will install your profile.
- For windows devices, open and run the installer. For other devices, you may need to save the installer and then run it using the appropriate commands for your operating system.
- Once installed, you should either be automatically connected to eduroam or be able to manually connect to it.

## **eduroam Setup for MacOS**

These instructions have been created using an Apple Mac running MacOS Tahoe (26.0.1), you might have a slightly different experience on different versions.

**IMPORTANT:** this guide is intended for use on a personal or non-University managed Apple Mac ONLY.  If you are using a University managed Apple Mac, you do not need to do any of the steps listed below – your device will have the required settings pushed to it automatically.

**Note:** If you have not connected to eduroam previously, skip to Step 2.

1. If you have connected to eduroam previously, you should first “Forget This Network”.

   1. Open Wi-Fi Settings, click the “...” next to eduroam, and select “Forget This Network”

![forget this network instruction](https://answers.atlassian.syr.edu/wiki/download/attachments/159941035/image-20260616-150512.png?api=v2)

2. Connect to another Wi-Fi network

   1. If you are on campus, use the AirOrangeX wireless network.
3. Open a web browser and go to <https://eduroamSU.syr.edu> . When prompted, login using your University NetID username and password.
4. You will be redirected to a page which will identify the operating system on your device, ensuring you are downloading the correct version of the App.

   1. Click “Download and Install the App” (Marvis Client)

![macOS Login Prompt](https://answers.atlassian.syr.edu/wiki/download/attachments/159941035/4a.png?api=v2)

**PLEASE NOTE:** you will need to return to this webpage to install the Profile.

5. Click “Confirm Download”- Install Marvis Client from the downloaded file

![Marvis Client Installer image](https://answers.atlassian.syr.edu/wiki/download/attachments/159941035/macos_5.png?api=v2)

**IMPORTANT:** once installed, the App must remain installed on your device to connect to eduroam.

6. Once the App has been installed, it will first show “No network profile configured”.

   1. **Go back to the webpage in your web browser**, and click “Install Network Profile”

![juniper app instructions part 1](https://answers.atlassian.syr.edu/wiki/download/attachments/159941035/6a1_macos.png?api=v2)![download and install network profile image](https://answers.atlassian.syr.edu/wiki/download/attachments/159941035/6a2_macos.png?api=v2)

7. Install the provided “Network Profile”.

![network profile install instructions](https://answers.atlassian.syr.edu/wiki/download/attachments/159941035/7_macos.png?api=v2)

8. Click “Finish” – you are now connected to eduroam.

![profile installation completed](https://answers.atlassian.syr.edu/wiki/download/attachments/159941035/8_macos.png?api=v2)

## Eduroam Security

Authentication is accomplished using a federated RADIUS server infrastructure. As an SU user, you must log in with your full email address to identify which RADIUS server in the eduroam infrastructure should handle your authentication attempt.

When you enter your credentials at a participating eduroam institution, the authentication dialogue is encrypted between your client device and SU’s RADIUS servers. Additionally, the authentication method used by SU is a challenge-response mechanism, so your client device never actually sends your password over the network.
