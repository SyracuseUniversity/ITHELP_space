The campus file servers retain up to 21 instances of your drives within the last 30 days.  File restore via Previs Versions is available from university managed Windows machines or via [RDS](https://answers.atlassian.syr.edu/wiki/spaces/ITHELP/pages/159941534/Remote+Desktop+Services+RDS), Syracuse University's remote desktop solution.

## Restore Previous Versions on a Campus or Personal Windows Computer

### Sign Onto a Campus Computer or Connect to rds.syr.edu

You'll need to be logged into a campus computer on site or through RDS (found at [rds.syr.edu](http://rds.syr.edu))

### Locate File Explorer

Locate the file explorer in your Windows operating systems.

![Windows explorer icon](https://answers.atlassian.syr.edu/wiki/download/attachments/159941122/explorer.JPG?api=v2)

### Select This PC

Open This PC

![Selection menu](https://answers.atlassian.syr.edu/wiki/download/attachments/159941122/this%20pc.JPG?api=v2)

### Open the Restore Window

With This PC open, you will see your drives listed.

![Drive link icon](https://answers.atlassian.syr.edu/wiki/download/attachments/159941122/h%20drive.JPG?api=v2)

Right click on the G drive and select Restore Previous Versions. A new window will open.

![File explorer window](https://answers.atlassian.syr.edu/wiki/download/attachments/159941122/1.png?api=v2)

### Identify Available Restore Points

In the new window select the Previous Versions tab.

![](https://answers.atlassian.syr.edu/wiki/download/attachments/159941122/previous%20versions%20tab.JPG?api=v2)

The drive will now seek out available previous version. A reminder that only instances of the last 30 days or 21 total restore points will be visible.

![File listing window](https://answers.atlassian.syr.edu/wiki/download/attachments/159941122/restore.JPG?api=v2)

### Open the Preferred Restore Point

Once you have identified your desired restore point, left-click to highlight it and select Open. A new window will now open showing you the G drive contents at the time of that login. You can now begin searching for your data.

![File listing window with selected](https://answers.atlassian.syr.edu/wiki/download/attachments/159941122/open.jpg?api=v2)

Restore Not Recommended

It is not recommended that you use the Restore option. Any data that was not properly saved in instanced beyond that date, or that you have worked on during your current session will be lost.
