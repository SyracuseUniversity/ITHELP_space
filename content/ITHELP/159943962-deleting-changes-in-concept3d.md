Changes that are made to the map in the CMS will not display on the front end until they are published. This way you can safely make and view changes without changing what the end user sees. All changes need to be published in order to take effect, including location and category modifications, and changes to the options as well.

It is possible to remove all and any changes **before they have been published**. You may not revert after the change has been published.

If there are changes eligible to be published, you will notice a red bubble in the **Publish** tab at the top with the number of eligible changes.

![](https://answers.atlassian.syr.edu/wiki/download/attachments/159943962/Screen%20Shot%202020-02-18%20at%209.51.40%20AM.png?api=v2)

## How to Delete Changes

---

1. Log into the Concept3D CMS: [Accessing the CMS for Concept3D](https://answers.atlassian.syr.edu/wiki/spaces/ITHELP/pages/159948603/Accessing+the+CMS+for+Concept3D)
2. Select the **Publish** tab
   ![](https://answers.atlassian.syr.edu/wiki/download/attachments/159943962/Screen%20Shot%202020-02-18%20at%209.50.20%20AM.png?api=v2)
3. Select the Discard Changes icon (Red Square; White X) next to the change you wish to discard
   ![](https://answers.atlassian.syr.edu/wiki/download/attachments/159943962/Screen%20Shot%202020-02-18%20at%2010.04.33%20AM.png?api=v2)
4. When a change is selected for discard, the text will turn red and the Discard Changes icon will turn light blue
   ![](https://answers.atlassian.syr.edu/wiki/download/attachments/159943962/Screen%20Shot%202020-02-18%20at%2010.09.24%20AM.png?api=v2)
5. Select all desired changes to be discarded, then select **Delete** at the bottom of the list 
   ![](https://answers.atlassian.syr.edu/wiki/download/attachments/159943962/Screen%20Shot%202020-02-18%20at%2010.10.54%20AM.png?api=v2)
