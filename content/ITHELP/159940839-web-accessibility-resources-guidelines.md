## Web Accessibility Checkers

How to Check for the Top 10 Accessibility Problems

- Step by step instructions for evaluating the most important accessibility checkpoints using the [WAVE Web Accessibility Evaluation tool](http://wave.webaim.org/)
- WebAIM - [Quick Reference: Testing Web Content for Accessibility](https://webaim.org/resources/evalquickref/evalquickref.pdf)
- [Sample University](https://ndat-ocr.github.io/issues/) - a site specifically designed to illustrate common accessibility problems

[WAVE Web Accessibility Tool](http://wave.webaim.org/)

- Tests against WCAG 2.1 standards.
- Use the checker online or install the Chrome Extension.
- See [WAVE Help](https://wave.webaim.org/help) and [WAVE Documentation](https://wave.webaim.org/api/docs?format=html) at WebAIM

[ANDI: Accessible name and Description Inspector](https://www.ssa.gov/accessibility/andi/help/howtouse.html)

- Free bookmarklet that tests against WCAG 2.1 and Section 508 standards
- Tests focusable elements, graphics, links/buttons, tables, headings, form fields, color contrast
