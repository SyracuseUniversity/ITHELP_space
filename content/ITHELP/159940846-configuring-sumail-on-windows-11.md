## Configuring Your Account to the Desktop Outlook App

### Step 1: Install Outlook

The desktop Outlook app is available for students, faculty, and staff as part of the Office365 package which can be downloaded by logging in to <https://m365.cloud.microsoft/apps> using your SU email address and password. Once logged in, click on the "Install Apps" button in the top-right corner, then choose “Microsoft 365 apps” This a large file, so it may take some time to download and install.

**Note for faculty/staff: If you are using an SU-provided computer, Outlook is already installed in most cases. If it is not installed, contact your** [**academic**](https://its.syr.edu/contact_its/school-and-college-support-contact-information/)**or** [**administrative**](https://its.syr.edu/contact_its/departmental-support-contact-information/)**IT support.**

![A screenshot of the Microsoft 365 apps website with an arrow pointing to Install apps](https://answers.atlassian.syr.edu/wiki/download/attachments/159940846/Screenshot%202026-06-17%20122323.png?api=v2)

### Step 2: Open Outlook

Type "Outlook" in the "Type here to search box" at the bottom-left of your screen, then click on the app to open it.

![A screenshot of a Windows 10 search result for the Outlook app is shown](https://answers.atlassian.syr.edu/wiki/download/attachments/159940846/2.png?api=v2)

### Step 3: Add Your Account

Select File > Add Account

![A screenshot of an arrow and circle pointing to the File menu location in the Outlook app is shown](https://answers.atlassian.syr.edu/wiki/download/attachments/159940846/3.png?api=v2)![A screenshot of the Outlook app file menu with an arrow and circle pointing to the Add Account button is shown](https://answers.atlassian.syr.edu/wiki/download/attachments/159940846/4.png?api=v2)

### Step 4: Enter Your Email and Select "Office 365"

Enter your SU email address and press "Connect". If prompted, choose Office 365 as the account type.

![A screenshot of the box prompting to type your email address is shown](https://answers.atlassian.syr.edu/wiki/download/attachments/159940846/5.png?api=v2)![](https://answers.atlassian.syr.edu/wiki/download/attachments/159940846/image2020-1-31_10-5-35.png?api=v2)

### Step 5: Enter Password

If prompted, enter your password, then select OK > Finish to start using your email account in Outlook.

![A screenshot of the Windows Security box asking the user to type in the email password is shown](https://answers.atlassian.syr.edu/wiki/download/attachments/159940846/7.png?api=v2)
