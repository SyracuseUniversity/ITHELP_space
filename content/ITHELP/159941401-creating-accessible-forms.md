## Workshop

[Creating Accessible Forms (Fall 2021) [PowerPoint with Notes]](https://answers.atlassian.syr.edu/wiki/download/attachments/159941401/Creating-Accessible-Forms.pptx?version=3&modificationDate=1636558620000&cacheVersion=1&api=v2)

[Form Accessibility Checklist (.docx)](https://answers.atlassian.syr.edu/wiki/download/attachments/159941401/Form%20Accessibility%20Checklist.docx?version=2&modificationDate=1638541750000&cacheVersion=1&api=v2)

Please note: This workshop instructs form creators how to make their forms accessible in various authoring tools. It is assumed that you already know how to create the forms.

- What makes a form accessible?
- How to test keyboard navigation
- Accessible Word, PDF, Excel forms
- Tips for Frevvo, Qualtrics, and WordPress
- HTML forms
- Using accessibility checkers for forms (WAVE, SiteImprove, etc.)
- Common accessibility errors with forms
